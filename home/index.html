Pre-Flight Diagnostics

启动前 6 维网络与风控体检

在向 Claude Desktop 放行任何字节之前，ClaudeSafe 先行完成六项交叉验证，任一高危项不通过即直接阻断启动。

01 通道探测

本地代理通道检测

自动读取 Windows 系统代理并扫描常见本地代理端口（7890 / 7897 / 10808 / 10809 等），同时识别 TUN 虚拟网卡与进程状态，确认上游代理可用性与延迟。

02 高危阻断

出口 IP 与地区合规检测

并发/级联探测多个 GeoIP 源，实时确认当前代理出口国家/地区。若出口位于受限或封禁地区（如 CN、HK、MO、RU 等），直接触发高危阻断，严禁启动。

03 风控评估

IP 属性与机房纯净度评估

自动识别 IP 的 Hosting / Proxy 标记与常见云厂商、共享机房 ASN，提前提示高并发共享机房 IP 可能带来的 Anthropic 风控权重风险。

04 漂移预警

历史 IP 漂移防风控对比

本地持久化记录上次安全登录使用的出口 IP、ASN 与国家代码；若本次启动发生跨国跳变或节点频繁切换，立即提示异常漂移预警，避免触发异地风控。

05 防泄漏验证

Anthropic 连通性与分流防泄漏

直接经由选定代理请求 https://claude.ai/cdn-cgi/trace 验证真实出口归属地，彻底堵住「GeoIP 走了代理、但 Claude 域名误走 DIRECT」的隐蔽分流漏洞。

06 环境校验

系统时区与环境一致性检查

校验当前 Windows 系统时区（UTC 偏移）与出口 IP 所在地理区域是否存在显著偏差，帮助用户识别潜在指纹不一致风险并给出调整建议。

Architecture & Circuit Breaker

本地守门代理与运行期断流保护

启动前检查代理与出口环境，并在会话期间定期监控受控代理连接。检测到异常后锁定 Gatekeeper；实际流量覆盖范围取决于 Claude Desktop 各组件的网络实现。

⚡ 检测到异常后快速断流

RuntimeWatchdogService 每 3 秒巡检上游代理连通性、每 15 秒校验出口 IP。检测到异常后锁定 GatekeeperProxyServer，并尝试切断其管理的活跃连接。由于采用定时巡检，异常发生到被发现之间可能存在时间窗口；该机制不承诺零延迟，也不代表能够覆盖应用的全部网络连接。

⏳ 5 分钟冷静期与置顶熔断

置顶弹出 CircuitBreakerWindow 紧急熔断窗口：可选择「保持断网进入 5 分钟冷静期」，待 VPN 恢复并自动/手动复检通过后无损恢复；或选择立即强杀全部 Claude 进程树。

🛡️ 退出无痕还原与常态防裸连

后台驻留守护期间通过防火墙出站规则、Hosts 黑洞（管理员模式）及进程看门狗拦截未经体检的直接双击启动；彻底退出 ClaudeSafe 时若检测到 Claude Desktop 仍在运行会弹窗确认是否同步退出，并无痕还原所有系统代理、防火墙规则与 Hosts 设置；长按主界面星芒 Logo 1 秒可临时解锁 3P 模式。

FAQ

ClaudeSafe 常见问题

关于 ClaudeSafe 的用途、系统支持、网络保护范围与使用边界。

ClaudeSafe 是什么？

ClaudeSafe 是一款面向 Windows 的 Claude Desktop 网络安全启动器。它在启动前检查代理和出口网络环境，并通过本地 Gatekeeper 代理引导应用网络请求；运行期间定期检查代理连通性与出口 IP 变化，检测到异常后锁定受控代理连接。

ClaudeSafe 是 Anthropic 官方产品吗？

不是。ClaudeSafe 是独立社区项目，与 Anthropic、Claude 官方没有隶属、背书或支持关系。

ClaudeSafe 能保证 Claude 账号不被封禁吗？

不能。ClaudeSafe 主要提供本地网络诊断、代理连接监控和意外直连风险缓解，无法控制服务提供方的账号资格判断或风控决定，也不保证避免账号限制或封禁。

ClaudeSafe 能接管 Claude Desktop 的全部网络流量吗？

ClaudeSafe 会通过启动参数和代理环境变量引导 Claude Desktop 的网络请求经过本地 Gatekeeper。应用的部分组件可能使用独立网络实现，因此不能仅凭代理配置保证所有请求均被接管，实际覆盖范围需要独立测试。

ClaudeSafe 的运行期检查频率是多少？

当前版本每 3 秒检查上游代理端口连通性，每 15 秒检查出口 IP 是否变化。因此异常发生到下一次巡检发现之间可能存在时间窗口，项目不承诺零延迟检测。

ClaudeSafe 支持哪些系统？

当前发布的程序面向 Windows 10 和 Windows 11 x64，使用 .NET 8 与 WPF 开发，不是原生 macOS 或 Linux 应用。
